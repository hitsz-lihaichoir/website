# 🏛️ 乐团组织架构

荔海合唱团隶属于哈尔滨工业大学（深圳）学生艺术团，承担我校诸多大型文艺演出的合唱表演。

---

## 👥 组织架构

| 部门 | 职责 |
|------|------|
| **管理层** | 统筹排练、选曲与艺术指导 |
| **指挥** | 统筹排练、选曲与艺术指导 |
| **女高声部** | 负责 Soprano 声部排练与考勤 |
| **女低声部** | 负责 Alto 声部排练与考勤 |
| **男高声部** | 负责 Tenor 声部排练与考勤 |
| **男低声部** | 负责 Bass 声部排练与考勤 |
| **钢琴伴奏** | 排练与演出钢琴伴奏 |

---

## 📞 加入我们

荔海合唱团每学期初面向全校招新，欢迎热爱合唱的同学加入！

> 🎶 具体招新时间请关注[「招新专区」](/recruitment/)及校内公告。
